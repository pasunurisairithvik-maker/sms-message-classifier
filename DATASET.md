# Dataset attribution
Almeida, T. & Hidalgo, J. (2011). SMS Spam Collection [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CC84.
Source: https://archive.ics.uci.edu/dataset/228/sms+spam+collection
UCI lists CC BY 4.0: https://creativecommons.org/licenses/by/4.0/
The downloader converts original label-tab-message records into label,text columns. Normalization/deduplication happens in training; the CSV retains original records. Raw dataset text and generated error examples may contain public phone numbers or URLs. Do not contact numbers or follow message links.
The data is historical English SMS, not current fraud messages and not customer support tickets. Current-world performance is unmeasured. Dataset license is separate from repository code licensing.
